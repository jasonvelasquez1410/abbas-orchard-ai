1 1-Line Embed Installation

Paste this single script tag right before the closing </body> tag on your website layout:

<!-- The Abba's Orchard 24/7 AI Admissions Assistant Widget -->
<script src="https://abbas-orchard-ai.vercel.app/abbas-widget-embed.js" defer></script>

2 Framework-Specific Placement

For Laravel & Inertia.js (Current Stack): Place the tag into your primary layout blade file (e.g. resources/views/layouts/app.blade.php or master.blade.php) right before </body>.

    ...
    <!-- Floating 24/7 Admissions Assistant -->
    <script src="https://abbas-orchard-ai.vercel.app/abbas-widget-embed.js" defer></script>
</body>
</html>

3 Optional Custom Attributes

The embed script works with zero configuration by default. You may optionally supply HTML data attributes to adjust placement or behavior:

Attribute Accepted Values Default Behavior
data-position "bottom-right" | "bottom-left" "bottom-right" Screen corner where the floating 🌱 bubble appears.
data-default-open "true" | "false" "false" Automatically expands the chat drawer upon page load.
data-server HTTPS URL Script Origin Direct backend API destination (auto-detected by default).

4 Content Security Policy (CSP) & CORS Guidelines

If your web server or Cloudflare reverse proxy enforces a strict CSP header, ensure the following directive whitelist is included:

Content-Security-Policy: 
  script-src 'self' https://abbas-orchard-ai.vercel.app;
  connect-src 'self' https://abbas-orchard-ai.vercel.app;
  style-src 'self' 'unsafe-inline';

5 Verification & Health Check (30 Seconds)

  • ✓ Floating Bubble: Verify the emerald green circular bubble appears at the bottom-right corner.
  • ✓ Drawer Expansion: Click the bubble to ensure the responsive admissions drawer slides up smoothly.
  • ✓ Interactive Campus Routing: Click "📍 CDO Alwana" or "🌾 Bukidnon La Granja" chips to test AI campus matching.
